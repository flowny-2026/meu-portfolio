# Meu Portfólio — versão atualizada

Esta versão substitui o portfólio HTML/CSS/JS antigo pela versão moderna baseada no projeto criado no Lovable.

## Stack
- React + TypeScript
- Vite
- Tailwind CSS v4

## Importante
O repositório Git do projeto antigo não foi incluído neste pacote. Isso é proposital: ao atualizar o GitHub, mantenha a pasta `.git` do seu repositório atual.

O vídeo do Venda Fácil foi ajustado para usar o vídeo do YouTube que já existia no portfólio antigo, porque o arquivo `.mp4` da hospedagem do Lovable não estava dentro do ZIP e não funcionaria no GitHub Pages.
